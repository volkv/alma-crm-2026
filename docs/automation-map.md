# Карта автоматизации

Что система делает на каждом из 14 шагов базового процесса «Работа с ВУЗ», чем это проверить и где
увидеть. Тот же состав показывает статья справки `/help/user/automation` («Справка» → «Карта автоматизации»); источник
обоих — реестр `src/lib/automation-map.ts`.

## Как устроено

- **Шаг** — стадия процесса `b2b` (`src/lib/server/stages/definitions.ts`), названная ключом. Название
  страница берёт из процесса, поэтому карта не расходится с доской.
- **Пункт** — одна автоматизация: вид, что делает система, проверяемый результат, экран «Где это».
- **Вид**: «Делает система» — результат без ручного ввода; «Помогает сотруднику» — система готовит,
  решает человек; «Контролирует» — без доказательства дальше не пройти или тревогу поднимает система.
- **Статус** `in_progress` — «в работе»: пункт ещё не выпущен и за сделанное не выдаётся.
- **Экран** назван идентификатором из реестра подсказок (`src/lib/onboarding/screens`): оттуда берутся
  адрес, право и статья справки. Ссылки на экран, закрытый роли, страница не показывает.
- **Числа** — только из журнала обмена (`listExchangeMessages`) и только с правом
  `integrations.manage`: принятые заявки с сайта, заявки на группы в LMS, принятые результаты групп.
  Журнал обмена без области доступа (`access-matrix.md`, раздел 4), поэтому числа — итог по журналу,
  а не по области человека. Периода у фильтра журнала нет — числа «всего», не «за 30 дней».

Модульная проверка `tests/unit/automation-map.test.ts` держит три вещи: шаги совпадают со стадиями
процесса и их порядком, у каждого шага 1–3 пункта, каждая ссылка ведёт на существующую страницу со
статьёй справки.

## Как добавить пункт

1. Дописать пункт в `AUTOMATION_STEPS` (или `AUTOMATION_CROSS_CUTTING`) с экраном из реестра
   подсказок. Экран записи (`[id=uuid]`) не годится: у ссылки карты нет конкретной записи — берут
   экран раздела и уточняют подпись полем `where`.
2. Выпущенный пункт — `status: 'ready'`; ещё не выпущенный — `'in_progress'`, и снять пометку той же
   задачей, что выпускает функцию.
3. Обновить таблицу выше и статью справки `src/lib/help/content/user/11-automation.md`.
